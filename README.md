# T-POS Mobile

Android app releases for T-POS (TechBits Systems).

## Download

Latest APK: https://github.com/techbits-systems/tpos-mobile/releases/latest

Or open the T-POS website, go to the sign-in page and tap "Download the Android app".

## Install

1. Open the downloaded `TPOS-x.y.z.apk` on the phone.
2. If Android asks, allow installing apps from this source, then tap Install.
3. If Play Protect shows a warning, tap More details, then Install anyway.
4. Open T-POS and sign in with your normal T-POS email and password.

Updates install over the existing app and keep its data and settings. The app shows an "Update available" banner when a newer release is published here.
